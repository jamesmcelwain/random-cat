Privacy & security — this is a local-only tool

Your files never leave your computer. Markdown Studio is a single, self-contained HTML file. Every file you open, edit, and save is read, rendered, and written entirely inside your own browser. There is no server, no upload, no account, no analytics, and no telemetry — file contents are never sent over the network to anyone, including the author.

How opening & saving works. Files are handled in-browser via the standard File API and, on Chromium browsers (Chrome/Edge), the File System Access API for saving changes back to the original file. Everywhere else, saving downloads a .md file to your machine. Nothing is transmitted in either case.

No external requests at all. This page loads nothing from the internet — no fonts, scripts, styles, or trackers from any third party. It uses your operating system's built-in fonts, so it renders and runs identically with your network disconnected. The only time it ever reaches the internet is if you deliberately click the author-credit link to GitHub.

Because everything runs client-side with no external dependencies, you can verify all of the above by reading this file's source, or by running it with your network disconnected — it works exactly the same.
